# Unemployment Analysis with Python

This project performs exploratory data analysis on unemployment data in India to identify regional and temporal trends and understand changes during the COVID-19 period.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data cleaning and preprocessing
- Region-wise average unemployment analysis
- Month-wise unemployment trends
- Three-state time-series comparison
- Top 10 states with highest average unemployment
- Correlation heatmap
- Pre-COVID vs Post-COVID comparison
- Key insights and recommendations
